# שמרטף חכם (Smart Baby Monitor)

אפליקציית אנדרואיד עצמאית (ללא צורך באינטרנט) שמאזינה לרעשי רקע דרך המיקרופון,
ואם היא מזהה רעש/בכי שחוצה סף דציבלים למשך מספר שניות רצוף — היא מבצעת אוטומטית
שיחת טלפון סלולרית רגילה למספר שהוגדר מראש.

## מבנה הפרויקט

```
BabyMonitor/
├── app/
│   ├── src/main/
│   │   ├── AndroidManifest.xml
│   │   ├── java/com/example/babymonitor/
│   │   │   ├── MainActivity.kt        # מסך Compose + ניהול הרשאות
│   │   │   ├── MonitorService.kt      # Foreground Service: מיקרופון + חיוג
│   │   │   ├── MonitorState.kt        # מצב משותף בין ה-Service למסך
│   │   │   └── ui/theme/              # Material 3 theme
│   │   └── res/                       # אייקונים (וקטוריים), strings
│   └── build.gradle.kts
├── build.gradle.kts
├── settings.gradle.kts
└── .github/workflows/build.yml        # בנייה אוטומטית של APK
```

## איך זה עובד

1. **Foreground Service** (`MonitorService`) שומר על תהליך פעיל גם כשהמסך כבוי,
   עם התראה קבועה (נדרש לפי מדיניות אנדרואיד המודרנית) וסוג שירות `microphone`.
2. השירות דוגם מהמיקרופון באמצעות `AudioRecord`, מחשב עוצמת קול משוערת בדציבלים
   מתוך RMS של הדגימות, ובודק האם היא חוצה את הסף שהוגדר (ברירת מחדל 70dB) למשך
   הזמן שהוגדר (ברירת מחדל 5 שניות).
3. כשהתנאי מתקיים, מופעל `Intent.ACTION_CALL` לחיוג ישיר למספר שהוזן במסך.
   קיים "צינון" (cooldown) של דקה בין שיחה לשיחה כדי למנוע חיוגים חוזרים.
4. המסך (`MainActivity`, Jetpack Compose / Material 3) כולל שדה להזנת מספר טלפון,
   סליידרים לכיוון רגישות ומשך זמן, וכפתור גדול שמשנה צבע (ירוק/אדום) בהתאם למצב.

## הרשאות נדרשות

- `RECORD_AUDIO` — האזנה למיקרופון
- `CALL_PHONE` — ביצוע שיחה אוטומטית
- `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MICROPHONE` — פעולה ברקע עם מסך כבוי
- `POST_NOTIFICATIONS` — הצגת ההתראה הקבועה (אנדרואיד 13+)

כל ההרשאות מבוקשות בזמן ריצה במסך הראשון.

## הפעלה מקומית (Android Studio)

1. פתחו את התיקייה `BabyMonitor` כפרויקט קיים ב-Android Studio (Koala ומעלה מומלץ).
2. תנו ל-Gradle Sync לרוץ (מוריד את התלויות אוטומטית).
3. הריצו על מכשיר פיזי (מומלץ — מיקרופון וחיוג לא תמיד עובדים טוב באמולטור).

## בנייה אוטומטית ב-GitHub Actions

1. צרו מאגר חדש ב-GitHub והעלו אליו את כל תוכן התיקייה הזו (כולל `.github`).
2. בכל `push` לענף `main` (או הפעלה ידנית דרך "Run workflow") ה-workflow
   `build.yml` יריץ בנייה של APK דיבאג.
3. ה-APK הגמור יופיע כ-Artifact בעמוד ה-Actions של המאגר, תחת השם
   `baby-monitor-debug-apk` — אפשר להוריד אותו משם ולהתקין ישירות על מכשיר.

> שימו לב: זהו build **debug** לא חתום, מיועד לבדיקה אישית. עבור הפצה רחבה יותר
> יש לחתום את ה-APK עם keystore ולעדכן את ה-workflow בהתאם.

## הערות בטיחות ושימוש אחראי

- זו אפליקציית עזר בלבד ו**אינה תחליף** לפיקוח הורי/מבוגר על התינוק.
- זיהוי הרעש מבוסס על עוצמת קול (דציבלים) ולא על זיהוי בכי סמנטי, כך שייתכנו
  זיהויי שווא (למשל טלוויזיה, שיפוצים) או פספוס מקרים (רעש רקע גבוה קבוע בחדר).
- שיחת חירום אוטומטית תלויה בכיסוי סלולרי תקין ובכך שהמספר שהוגדר זמין לענות.
- מומלץ לבדוק את האפליקציה בתנאים מבוקרים לפני הסתמכות עליה בפועל.
